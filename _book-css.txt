1.1 Principe

Le CSS est un langage informatique qui permet de décrire la présentation d'un document écrit en HTML ou
XML (y compris les dialectes XML comme SVG, MathML ou XHTML).
Enjeux :

    -- séparation entre la structure & la présentation
    -- présentation selon le media (print / screen / tv...)
    -- cascade des styles : combinaison de différentes sources de style

1.2 Exemple : CSS Zen Garden

Le projet CSS Zen Garden a été lancé en 2003 par Dave Shea. Il s'agit d'un projet qui met en avant la puissance
du CSS en permettant aux designers de créer des mises en page uniques et créatives en utilisant le même
contenu HTML. Le site présente une série de designs réalisés par des designers du monde entier, tous basés
sur le même fichier HTML.

1.3 Insérer du CSS dans une page

Il existe trois façons d'associer du CSS à un document HTML :

1.3.1 1. Feuille de style externe (recommandé)

Le CSS est écrit dans un fichier séparé (par exemple style.css), relié à la page depuis le <head> avec
la balise <link> :

<head>
   <link rel="stylesheet" href="style.css" />

</head>

C'est la méthode à privilégier : un même fichier peut mettre en forme plusieurs pages, et le fond (HTML)
reste bien séparé de la forme (CSS).

BARBIER JeanMatthieu  3
CSS                                                                 20260623

1.3.2 2. Feuille de style interne

Le CSS est écrit dans une balise <style>, placée dans le <head> de la page. Pratique pour une page unique
ou un essai rapide :

<head>
   <style>
       h1 {
          color: red;
       }
   </style>

</head>

1.3.3 3. Style en ligne (inline)

Le CSS est écrit directement sur la balise, via l'attribut style :

<h1 style="color: red;">Titre</h1>

Á    Le style inline est à éviter : il mélange le fond et la forme, n'est pas réutilisable, et est difficile
     à maintenir. On le réserve à des cas très ponctuels.

Références : MDN Sélecteurs : MDC CSS Selectors

1.4.1 Syntaxe

Le CSS associe des règles de représentation à des éléments sélectionnés dans le document HTML. Une
règle de représentation est composée d'un ou plusieurs sélecteurs et d'une déclaration qui ellemême est
composée d'une ou plusieurs propriétés et de leur valeur.
Les propriétés sont tout ce qui peut être appliqué à un élément : couleur, taille, marge, police, etc.

Chaque déclaration se termine par un pointvirgule ;, et le bloc de déclarations est délimité par des acco

1.4.2 Sélecteurs

Un sélecteur désigne les éléments du document auxquels une règle s'applique. On peut cibler les éléments
par leur type (la balise), leur position dans l'arbre, leur classe, leur identifiant, leurs attributs, ou leur état
(pseudoclasses).

1.4.2.1 Sélecteurs simples, hiérarchie

    1. li == sélectionne toutes les balises li du document
    2. article li == sélectionne toutes les balises li qui sont des descendants (pas forcément directs)

        d'un article
    3. article > ul == sélectionne tous les ul qui sont enfant direct d'un article
    4. article > ul > li == sélectionne tous les enfants direct d'un ul descendant direct d'un article
    5. h1 + p == sélectionne toutes les balises p qui suivent immédiatement un h1
    6. h1 ~ p == sélectionne toutes les balises p qui suivent (immédiatement ou non) un h1 et qui ont le

        même parent

Exemple :

li {
   background-color: yellow;

}
article li {

   border: 1px solid red;
}
article > ul {

   background-color: blue;
}
article > ul > li {

   border: 3px solid green;
}
h1 + p {

   background-color: orange;
}
h1 ~ p {

   border: 3px solid purple;
}

1.4.3.1 Toutes les propriétés

Les propriétés régissent tous les aspect de la présentation d'un élément : arrière plan, bordures, polices,

    -- background-image : url(`http ://adresse/image')

1.4.3.2 Valeurs

Les valeurs dépendent de la propriété; certaines propriétés acceptent des "mots" prédéfinis (ex :
text-align: left|right|start|end|center|justify;), d'autres acceptent des valeurs
dimensionnelles (ex : font-size: 12px;), d'autres acceptent des valeurs de type couleur (ex : color:
#RRGGBB;).

1.4.3.2.1 Valeurs dimensionnelles

    -- px : pixels = pixels "réels" (ex : 12px) sur l'écran
    -- pt : points = 1/72 de pouce (ex : 12pt)
    -- mm : millimètres (ex : 12mm) et cm : centimètres (ex : 12cm)
    -- em : taille de la police du parent
    -- rem : taille de la police de l'élément racine
    -- % : pourcentage de la taille de l'élément parent
    -- vh : 1% de la hauteur de la fenêtre
    -- vw : 1% de la largeur de la fenêtre
    -- vmin : 1% de la plus petite dimension de la fenêtre
    -- vmax : 1% de la plus grande dimension de la fenêtre
    --...

1.4.3.2.2 Valeurs de couleur

Référence MDN Color value

2 Cascade et héritage

2.1 Cascade

Si plusieurs propriétés sont applicables pour un élément, il faut savoir comment choisir la bonne. La cascade
est l'ordre de priorité des propriétés CSS. Il y a trois niveaux de priorité :

    1. importance (!important, par exemple color: red!important)
    2. sélectivité : du plus spécifique au plus général.

        1. la propriété style de l'élément
        2. une propriété définie pour l'id d'un élément
        3. une propriété définie par classe ou attribut
        4. une propriété définie pour l'élément

    3. ordre d'apparition dans la feuille de style (le plus bas l'emporte)

®    Calculer la spécificité
     La spécificité d'un sélecteur se compte comme un triplet (id, classe, élément) : on
     compte le nombre d'id, puis de classes (ou attributs, ou pseudoclasses), puis de balises qu'il
     contient. On compare ensuite ces triplets de gauche à droite.
     Par exemple :

         -- #p1 (un id) vaut (1, 0, 0)
         -- .c1 (une classe) vaut (0, 1, 0)
         -- div p (deux balises) vaut (0, 0, 2)
         -- p (une balise) vaut (0, 0, 1)
     On lit ces triplets de gauche à droite, comme on comparerait des nombres : (1, 0, 0)
     l'emporte sur tout triplet commençant par 0 (un seul id bat n'importe quel nombre de classes
     ou de balises). Et (0, 1, 0) l'emporte sur (0, 0, 2) : une seule classe bat deux balises,
     car on compare d'abord la colonne des classes. C'est ce qui explique les cas les plus subtils
     de l'exemple cidessous.

2.2 Héritage

Certaines valeurs de propriété appliquées à un élément sont appliquées à ses enfants, d'autres ne le sont
pas :

    -- héritées : font-family, color, ...
    -- non héritées : margin, padding, border, ...

En pratique, les propriétés liées au texte sont généralement héritées (color, font-family, font-size,
line-height, text-align...), tandis que celles liées à la boîte et à la mise en page ne le sont pas
(margin, padding, border, background, width...).

®    Cascade  héritage
     La cascade choisit, parmi plusieurs règles qui visent le même élément, laquelle l'emporte.
     L'héritage transmet une valeur d'un élément à ses descendants lorsqu'aucune règle ne les
     vise directement.

2.2.1 Forcer ou bloquer l'héritage

Quelques valeurs spéciales, disponibles pour toute propriété, permettent de contrôler l'héritage :

    -- inherit : force la propriété à prendre la valeur du parent (même si elle n'est pas héritée par défaut)
    -- initial : remet la propriété à sa valeur par défaut (celle définie par le standard CSS)
    -- unset : se comporte comme inherit si la propriété est héritable, sinon comme initial

/* Par défaut, un lien est bleu : on le force à prendre
     la couleur du texte qui l'entoure */

a{
   color: inherit;

}

®    Padding ou margin?

3.1.1 Dimensions : width et height

width (largeur) et height (hauteur) fixent la taille de la zone de contenu. On peut aussi borner ces dimen
sions :

    -- min-width / max-width : largeur minimale / maximale
    -- min-height / max-height : hauteur minimale / maximale
Les valeurs peuvent être absolues (px) ou relatives (% du parent, vw/vh...).

.encadre {
   width: 300px;
   max-width: 100%; /* ne dépasse jamais la largeur du parent */

}

Par défaut, un élément bloc occupe toute la largeur disponible et sa hauteur s'adapte à son contenu; il est
donc rare d'avoir à fixer height.

3.1.2 Margin, border et padding

margin, padding et border peuvent être réglés côté par côté ou d'un seul coup grâce à une notation
raccourcie :

    -- une valeur : les 4 côtés (padding: 10px;)
    -- deux valeurs : vertical puis horizontal (margin: 10px 20px;)
    -- quatre valeurs : haut, droite, bas, gauche (sens horaire)

On peut aussi cibler un seul côté : margin-top, padding-left, border-bottom...

.carte {
   padding: 20px; /* 20px sur les 4 côtés */
   border: 2px solid black; /* épaisseur, style, couleur */
   margin: 10px 0; /* 10px en haut et en bas, 0 à gauche et à droite */

}

La bordure se décrit par trois informations : épaisseur, style (solid, dashed, dotted...) et couleur. On
peut arrondir ses coins avec border-radius.

®    Centrer un bloc horizontalement
     Pour centrer une boîte de largeur fixe dans son parent, on met ses marges gauche et droite à
     auto :

     .carte {
        width: 300px;
        margin: 0 auto;

     }

     Attention, margin: auto ne fonctionne que sur un élément bloc dont la largeur est fixée.

3.1.3 box-sizing : ce que compte la largeur

Par défaut (box-sizing: content-box), width ne mesure que le contenu : le padding et la bordure
s'ajoutent à la largeur visible. Une boîte de width: 200px avec padding: 20px et border: 5px
occupe donc en réalité 200 + 2×20 + 2×5 = 250px -- souvent déroutant.

Avec box-sizing: border-box, width inclut le padding et la bordure : la boîte fait exactement
200px de large, quel que soit son padding. C'est beaucoup plus pratique, au point qu'on l'applique sou
vent à toute la page :

*{
   box-sizing: border-box;

}

3.2 Le flux normal

Sans aucune mise en page particulière, le navigateur place les boîtes selon le flux normal, qui dépend du
type de chaque élément (notion vue dans la partie HTML) :

    -- les éléments bloc (<p>, <div>, <h1>...) s'empilent verticalement, les uns sous les autres, chacun
        sur toute la largeur disponible ;

    -- les éléments en ligne (<a>, <span>, <strong>...) se placent les uns à la suite des autres hori
        zontalement, et reviennent à la ligne quand la place manque.

Les propriétés display, position et float servent justement à modifier ce flux pour obtenir d'autres
dispositions.

3.3 display : le type de boîte

La propriété display change la nature de la boîte :

    -- block : bloc (largeur du parent, retour à la ligne avant/après)
    -- inline : en ligne (largeur du contenu; width/height ignorés)
    -- inline-block : en ligne (reste dans le flux du texte), mais on peut lui donner une width, une

        height, un padding... -- pratique pour aligner plusieurs boîtes côte à côte sans flex
    -- none : l'élément disparaît complètement (il n'occupe aucune place, contrairement à visibility:

        hidden)
    -- flex, grid, table : modes de disposition avancés (vus plus loin)

3.4 position : positionner une boîte

La propriété position définit le référentiel dans lequel on déplace la boîte à l'aide des décalages top,
right, bottom, left :

    -- static : position par défaut (dans le flux normal ; les décalages n'ont aucun effet)
    -- relative : décalée par rapport à sa position normale, tout en gardant sa place dans le flux
    -- absolute : sortie du flux, positionnée par rapport à l'ancêtre positionné le plus proche (le pre

        mier parent qui n'est pas static)
    -- fixed : sortie du flux, positionnée par rapport à la fenêtre (reste fixe au défilement)
    -- sticky : reste dans le flux puis se fige lorsqu'on atteint un seuil de défilement (entre relative et

        fixed)

z-index gère la superposition des boîtes qui se chevauchent : plus la valeur est élevée, plus l'élément
passe audessus.

3.5 float et clear

Historiquement utilisé pour les mises en page (aujourd'hui remplacé par flex et grid), float sert surtout
à faire contourner un élément par le texte (par exemple une image entourée de texte) :

    -- float: left / right : l'élément flotte à gauche/droite, le contenu suivant l'enroule;
    -- clear: left / right / both : force un élément à passer sous les éléments flottants.

4.1 Le responsive design

Une même page web est consultée sur des écrans très différents : grand moniteur, ordinateur portable, ta
blette, téléphone... Le responsive design (« design adaptatif ») consiste à concevoir une page dont la mise
en page s'adapte automatiquement à la taille de l'écran : les contenus se réorganisent, les colonnes s'em
pilent, les images se redimensionnent.
Deux ingrédients de base :

    -- une page fluide (largeurs en %, en vw, ou avec max-width plutôt qu'en px fixes);

    -- la balise <meta name="viewport"> dans le <head>, qui indique au téléphone de ne pas « dé
        zoomer » la page :

<meta name="viewport" content="width=device-width, initial-scale=1.0" />

En savoir plus : MDN -- Responsive design

4.2 Les media queries

Une media query applique des règles CSS seulement si une condition est remplie -- le plus souvent une
condition sur la largeur de l'écran. C'est l'outil qui permet de changer la mise en page selon l'appareil.

/* Style par défaut (s'applique partout) */
body {

   font-size: 18px;
}

/* Sur les écrans de moins de 600px de large (téléphones) */
@media (max-width: 600px) {

   body {
       font-size: 14px;

   }
}

On utilise surtout max-width (« jusqu'à telle largeur ») et min-width (« à partir de telle largeur »). Les
largeurs où la mise en page change s'appellent des points de rupture (breakpoints).

En savoir plus : MDN -- Media queries

4.3 Flexbox

Flexbox est un mode de disposition qui aligne facilement des éléments sur une ligne (ou une colonne)
et répartit l'espace entre eux. C'est aujourd'hui la méthode la plus simple pour, par exemple, placer des
éléments côte à côte ou centrer un contenu.

On l'active en mettant display: flex sur le conteneur : ses enfants directs deviennent des éléments
flexibles alignés sur une ligne.

.barre {

   display: flex;

   justify-content: space-between; /* répartit l'espace horizontalement */

   align-items: center;  /* centre verticalement */

}

<div class="barre">
   <span>Logo</span>
   <span>Accueil</span>
   <span>Contact</span>

</div>

Quelques propriétés clés (sur le conteneur) :
    -- flex-direction : row (en ligne, défaut) ou column (en colonne)

    -- align-items : alignement dans le sens perpendiculaire (center, stretch...)

4.4 Grid

CSS Grid va plus loin que Flexbox : là où Flexbox aligne sur une dimension (une ligne ou une colonne), Grid
organise le contenu sur deux dimensions à la fois -- en lignes et colonnes, comme une grille. C'est l'outil
idéal pour des mises en page complètes (entête, barre latérale, contenu, pied de page).

.grille {

   display: grid;

   grid-template-columns: 1fr 1fr 1fr; /* trois colonnes de largeur égale */

   gap: 10px;         /* espace entre les cases */

}
